# Imagens da PV

Salve aqui com estes nomes exatos — o `index.html` referencia eles diretamente:

| Arquivo | Uso | Recorte |
|---|---|---|
| `turma-01.jpg` … `turma-08.jpg` | galeria das turmas anteriores | 4:3 |
| `luiz.jpg` | retrato do Luiz Gregatti | 4:5 vertical |
| `depo-01.jpg` … `depo-03.jpg` | fotos dos depoimentos | quadrado |

A galeria e o retrato **se escondem sozinhos** enquanto o arquivo não existir, e
aparecem automaticamente quando ele entrar — não precisa mexer no código.

Depois de adicionar imagens, rode `python3 build.py` para regerar a versão publicada.

Confirmar autorização de uso de imagem dos participantes antes de publicar.
